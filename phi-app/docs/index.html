Experimental research reference

Phi-Calculus

A project for exploring phi-related mathematical constructions, deterministic visualizations, project-local evaluation rubrics, and possible relationships to multi-agent system design.

Evidence boundary: the repository contains implemented calculations, visual simulations, and model-assisted heuristic evaluation. It does not currently establish that phi-based structures improve AI accuracy, hallucination resistance, governance, compliance, orchestration performance, or computational complexity. Historical claims that imply such effects remain hypotheses unless supported by a reproducible experiment.

Mathematical constructions

φ = (1 + √5) / 2 ≈ 1.61803398875

The current visualizer uses the golden ratio, the golden-angle expression π(3 − √5), Fibonacci-count display parameters, and phi-weighted geometric transforms. These are mathematical inputs to the implementation. Their use does not imply that the resulting visualization or AI-oriented interpretation has empirical efficacy.

Prompt evaluator

The evaluator sends a prompt to a configured model and asks it to apply one of several project-local rubrics. Returned numerical scores and classifications are labeled MODEL_HEURISTIC. They are advisory model judgments, not calibrated measurements, proofs, certifications, security assessments, or DGAF authorization.

Relationship to PDMAL

PDMAL means Phi-Driven Multi-Agent Lattice in the surrounding research. Dodecahedral and other graph structures may be represented or studied here, but this application does not transfer experimental validation from PDMAL or DGAF. Structural graph facts and deterministic calculations are distinct from evidence that a topology improves multi-agent performance.

Relationship to DGAF

DGAF = Dynamic Governance Agentic Formation. DGAF is a separate governance/evaluation research track. Phi-Calculus may reference its terminology or provide experimental interfaces, but this application is not a DGAF authorization authority, compliance layer, security boundary, or proof of DGAF effectiveness.

Research personas

Names such as Apogee, DemiJoule, Reciprocity, Herald, Prof Prodigy, Reson, Echolette, and Lyra are project-local explanatory or analytical roles. A persona label does not establish independent review, distinct custody, professional credentialing, or an autonomous agent implementation unless the corresponding executable system and evidence explicitly demonstrate it.

What would promote a claim

Promotion beyond implementation requires a predeclared target metric, baseline/comparator, reproducible dataset or task set, deterministic or recorded configuration, repeated trials where appropriate, preserved negative results, and an evaluation that is independent of the code path or prompt that generated the claim. Deployment health and attractive visualization are not substitutes for that evidence.
